# WiNspire
Hi! I am Malik Idrees Hasan Khan. I am a 17-year-old from India, and I primarily spend my free time building silly things.

WiNspire is one of those silly things - it is a fork of tiny386 for the TI-Nspire CX II family of graphing calculators. It can boot every major release of
Windows from Windows 1.0 to Windows XP.

WiNspire has two modes - **Native** and **Server**.

- In **Native** mode, everything is stored on the calculator. The release profile provides 16 MB of RAM and 256 KB of VRAM, making it best suited to small Windows 1.x through 95 installations that fit in the calculator's storage.


- In **Server** mode, the disk image is streamed sector by sector from a Windows PC using WRBP. LinuxLoader2 replaces TI-OS with a minimal Linux environment. The release profiles provide 44 MB of RAM and 2 MB of VRAM, making Server suitable for Windows 95 through XP.
